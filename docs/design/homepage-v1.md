# Homepage v1

## Purpose

This mockup is a visual reference for the homepage.

It illustrates the intended layout, visual hierarchy, spacing and overall style.

It is **not** intended to be reproduced pixel-perfect.

---

## Implementation Guidelines

When implementing the homepage:

- Follow the overall layout and section order.
- Preserve the visual hierarchy.
- Match spacing proportions rather than exact pixel values.
- Use the project's design system and design tokens.
- Build reusable Vue components.
- Prioritize responsive design and accessibility.

Technical constraints and reusable architecture always take precedence over visual perfection.

---

## Notes

This design may evolve during development.
The implementation can differ where necessary to improve usability, responsiveness or maintainability.
